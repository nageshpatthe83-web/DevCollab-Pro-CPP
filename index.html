CodeSentry (OOP)

AlgoPro (DSA)

Empirical Big-O performance tracer fitting execution timings against theoretical curves.

  • Times execution across scaling inputs (N)
  • Counts comparisons, swaps, operations
  • Power-law regression curve fitting O(1) to O(N²)

CodeVault (DBMS & VCS)

Git-like version control database implementing Myers delta-storage and 3-way merge conflict detection.

  • Stores only incremental changes (saving 60%+)
  • SHA/FNV-1a commit hash integrity
  • 3-way merge conflict detector for teams
  • Commit DAG and timeline history
